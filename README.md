# Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application built using React. It allows users to browse houseplants, view plant details, add plants to a shopping cart, and manage cart items.

## Technologies Used
- React
- Vite
- Redux Toolkit
- React Redux
- JavaScript
- CSS

## Features
- Browse plants by category.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- Calculate the total cost of the cart.
